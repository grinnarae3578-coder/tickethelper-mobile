티켓 예매 도우미 Mobile 1.0

[중요] 이 ZIP 파일은 완성된 웹앱 소스입니다. 아이폰에 설치하려면 HTTPS 웹 주소로 게시해야 합니다.
ZIP 파일을 아이폰에서 열기만 해서는 홈 화면용 앱으로 설치되지 않습니다.

간단한 배포 예시 (GitHub Pages)
1. GitHub 계정으로 새 PUBLIC 저장소를 만듭니다. 예: tickethelper-mobile
2. ZIP 압축을 풀고 tickethelper_mobile 폴더 안의 파일들(index.html 등)을 저장소 최상위에 업로드합니다.
3. Settings > Pages > Build and deployment > Deploy from a branch, main / (root)를 선택해 저장합니다.
4. 게시된 https://계정.github.io/tickethelper-mobile/ 주소를 iPhone Safari로 엽니다.
5. Safari 공유 버튼 > 홈 화면에 추가 > 웹 앱으로 열기(표시되는 경우) > 추가.

주의: Public 저장소에는 코드가 공개됩니다. 공연명·예매 일정 등 개인 데이터는 업로드하지 않고 기기 로컬 저장소에만 기록합니다.
공연 등록 > 저장 > '캘린더 알림 추가' 버튼 > 다운로드된 ICS 파일을 iPhone 캘린더로 가져옵니다.
iOS 버전 및 다운로드 동작에 따라 파일 앱에서 .ics를 열거나 공유해야 할 수 있습니다. 캘린더에 30분, 10분, 1분 전 알림이 실제 등록되었는지 반드시 확인하세요.
웹앱 자체는 백그라운드 알림을 보내지 않습니다. 캘린더 등록이 필수입니다.
기기 변경/브라우저 데이터 삭제 전에 '일정 백업(JSON)'을 사용하세요.
실제 예매/좌석 선택/결제는 공식 예매 사이트에서 직접 진행합니다.
